Stage 02

DSP Conditioning

FFmpeg multi-stage filter: `afftdn` FFT noise suppression (-30dB floor), two-way silence stripping (-30dB), and `loudnorm` normalization to 16kHz mono.

Stage 03

Quantized Faster-Whisper

Stage 04

Stage 01 Details

Source Ingestion & Dynamic Routing

Module: src/transcribe_ambient.py

The pipeline monitors target directories for arbitrary multi-format media (`.wav`, `.mp3`, `.m4a`, `.aac`, `.amr`, `.3ga`). It immediately executes `ffprobe` to determine audio channel geometry and bitrates, while parsing regex timestamp patterns to establish canonical chronological file naming.

Key Engineering Advantages:
  • Zero-data loss handling of legacy phone codecs (`amrnb`/`amrwb`) and mobile voice memos.
  • Automated tagging: `[Voicemail]`, `[OBS_ScreenCap]`, `[EarSpy_Ambient]`.
  • Prevents duplicate processing by checking existing transcript signatures.
extract_metadata & determine_source Python 3.10+ 
def determine_source(filename, metadata, rules=None):
    if rules is None:
        rules = load_source_rules()  # Configurable via sources_config.json
    for rule in rules:
        if matches_source_rule(filename, metadata, rule):
            return rule.get("tag"), bool(rule.get("high_sensitivity", False))
    return None, False  # Clean fallback without Unknown_Source
